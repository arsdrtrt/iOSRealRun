Этот проект является модификацией [iOSRealRun-cli-17](https://github.com/iOSRealRun/iOSRealRun-cli-17) с обновлёнными зависимостями [pymobiledevice3](https://github.com/doronz88/pymobiledevice3).

Если при использовании возникнут неразрешимые ошибки, можно попробовать [этот репозиторий для ручного запуска](https://github.com/BiancoChiu/iOSEasyRun).

**Тестовая среда:**

- ОС: MacOS, Windows 11, Linux
- Версия Python: 3.13
- Версия iOS: 18.3.1

## Краткое руководство по использованию

### Предварительные условия

1. Система: `Windows`, `macOS`, `Linux` (для Linux см. [этот issue](https://github.com/BiancoChiu/iOSRealRun-cli-18/issues/4))
2. Версия iOS на iPhone или iPad: **17 или выше** (подходят 17 / 18 / 26)
3. Для Windows необходимо установить iTunes
4. Установлены `Python3` и `uv` / `pip3` (достаточно одного из них)
5. **Важно:** К компьютеру можно подключить **только одно** устройство iPhone или iPad, иначе будут проблемы.

### Шаги

1. Клонируйте проект и перейдите в его директорию.

2. Установите зависимости:

    ```shell
    # uv
    uv sync

    # pip
    pip3 install -r requirements.txt
    ```

3. Измените конфигурацию и файл маршрута (см. шаги 4, 5, 7 в [оригинальном README](https://github.com/iOSRealRun/iOSRealRun-cli/blob/main/README.md#%E4%BD%BF%E7%94%A8%E6%96%B9%E6%B3%95)).

4. Подключите устройство к компьютеру, разблокируйте его и нажмите «Доверять» в появившемся окне.

5. Запустите программу:

    - **Windows:** Откройте терминал (cmd или PowerShell) **от имени администратора**, перейдите в директорию проекта и выполните:

        ```shell
        # uv
        uv run main.py

        # pip
        python main.py
        ```

    - **macOS / Linux:** Откройте терминал, перейдите в директорию проекта и выполните:

        ```shell
        # uv
        sudo uv run main.py

        # pip
        sudo python main.py
        ```

    > **Примечание:** Права администратора/root нужны для создания TUN-устройства.

6. Следуйте инструкциям на экране. Если программа пишет, что устройство не подключено, на Windows убедитесь, что iTunes установлен (возможно, его нужно запустить), затем перезапустите программу. На шаге 3 убедитесь, что устройство подключено, разблокировано и доверено компьютеру.

7. Для завершения работы обязательно используйте `Ctrl + C`, иначе местоположение не восстановится.

8. Если местоположение не восстановилось, перезагрузите телефон.
